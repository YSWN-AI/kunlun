# 网文类型写作指南

> 针对不同网文类型的创作规范与爽点设计

---

## 一、都市类型

### 1.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 都市异能 | 现代都市+超能力 | 实力碾压、身份逆袭 |
| 都市重生 | 回到过去弥补遗憾 | 先知优势、打脸复仇 |
| 都市兵王 | 退役军人回归都市 | 霸气护美、以一敌百 |
| 都市神医 | 医术+都市生活 | 妙手回春、美人在怀 |

### 1.2 节奏规范

```
第1章：异能觉醒/重生回归（钩子要强）
第2-3章：初露锋芒（建立优势）
第4-6章：第一个大爽点（打脸/收获）
第7-10章：能力成长+危机（拉高期待）
第11-15章：第二个大爽点
...
```

### 1.3 常用套路

- 开局被看不起 → 展现实力 → 打脸
- 偶遇女主 → 产生羁绊 → 感情升温
- 发现商机/机会 → 利用先知优势 → 赚取第一桶金
- 得罪大少/权贵 → 反杀 → 身份揭露

### 1.4 禁忌事项

- 女主过于绿茶
- 男主动不动送钱送房（太假）
- 配角智商下线
- 升级太快导致战力崩塌

## 二、玄幻类型

### 2.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 东方玄幻 | 仙侠元素+修炼体系 | 境界突破、法宝认主 |
| 异世大陆 | 穿越到异世界 | 王者归来、创建势力 |
| 洪荒封神 | 上古神话背景 | 证道成圣、抢夺机缘 |
| 御兽流 | 契约妖兽/异兽 | 神兽追随、战宠进化 |

### 2.2 修炼体系设计

```
境界示例（东方玄幻）：
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 渡劫 → 仙人

每境界9层（1-9阶）
突破时必有异象/天劫
```

### 2.3 节奏规范

```
第1章：穿越/觉醒（建立身份）
第2-5章：修炼起步（小突破）
第6-10章：第一个机缘（大突破）
第11-20章：势力初成
...
```

### 2.4 常用套路

- 资质低下被嘲笑 → 奇遇逆袭
- 宗门考核 → 一鸣惊人
- 秘境探险 → 获得传承/法宝
- 仇人追杀 → 反杀/成长
- 红颜知己 → 共同成长

## 三、仙侠类型

### 3.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 传统仙侠 | 修仙问道 | 飞升长生、剑道至尊 |
| 凡人流 | 资质平庸+努力 | 小人物逆袭、步步为营 |
| 杀伐果断 | 快意恩仇 | 以杀止杀、睚眦必报 |
| 古典仙侠 | 文笔优美 | 意境深远、仙气飘飘 |

### 3.2 凡人流特点

| 要素 | 说明 |
|------|------|
| 资质平庸 | 主角不是天才，需要更多努力和机缘 |
| 资源匮乏 | 每一点资源都要争取 |
| 算计生存 | 需要智慧和谋略 |
| 谨慎行事 | 不轻易冒险 |

### 3.3 节奏规范

```
前期（筑基前）：积累期，以小冲突为主
中期（金丹-元婴）：势力期，建立门派/势力
后期（元婴后）：争霸期，参与大事件
飞升期：终极目标，证道长生
```

## 四、科幻类型

### 4.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 星际科幻 | 太空探索/星际战争 | 战舰征服、星际称霸 |
| 末世科幻 | 丧尸/灾难背景 | 异能觉醒、资源收集 |
| 未来都市 | 高科技+都市 | 科技致富、AI崛起 |
| 进化变异 | 生物进化 | 超能力觉醒、物种进化 |

### 4.2 科幻设定规范

- 科技树要自洽
- 不要过于YY（太假）
- 保持一定科学性
- 想象力要大胆但合理

## 五、游戏类型

### 5.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 全息网游 | 虚拟现实游戏 | 副本首杀、装备获取 |
| 游戏异界 | 穿越到游戏世界 | NPC觉醒、游戏机制 |
| 虚拟电竞 | 电竞职业选手 | 冠军之路、技术碾压 |
| 异界穿越 | 游戏技能带到异界 | 降维打击 |

### 5.2 游戏机制设计

```
等级系统：1-100级
职业：战士、法师、刺客、辅助等
副本：普通、困难、地狱
装备：白、绿、蓝、紫、橙、红
技能：主动、被动、觉醒技
```

## 六、历史类型

### 6.1 子分类

| 子类 | 特点 | 核心爽点 |
|------|------|----------|
| 架空历史 | 虚构朝代/世界 | 权谋争霸、开疆扩土 |
| 穿越历史 | 穿越到历史朝代 | 改变历史、辅佐明君 |
| 历史同人 | 依托历史人物 | 再现历史、名将对决 |

### 6.2 历史文要点

- 考据要严谨（架空可放宽）
- 说话方式要符合时代
- 制度要有历史依据
- 避免过度YY

## 七、通用写作技巧

### 7.1 开头写法

**黄金三章**：
1. 第一章：立人设、放钩子
2. 第二章：冲突/危机/机遇
3. 第三章：小高潮/第一个爽点

**禁忌开头**：
- 旁白式介绍（太无聊）
- 大段背景设定（劝退）
- 主角名字+身份+能力的流水账

### 7.2 爽点设计

**爽点节奏**：
```
小爽点：每500-1000字
中爽点：每3000-5000字
大爽点：每10000字以上
```

**爽点公式**：
```
爽点 = 期待 + 压抑 + 释放

期待：让读者知道主角能/会有什么
压抑：让主角暂时无法获得
释放：主角获得，读者满足
```

### 7.3 配角塑造

**反派塑造原则**：
- 有智商的反派更让人咬牙切齿
- 反派要有自己的立场和理由
- 脸谱化反派要有特点（最好笑点）

**女主塑造原则**：
- 有独立人格和故事线
- 不是花瓶，有自己的能力
- 与男主共同成长

### 7.4 节奏把控

**黄金比例**：
- 冲突：发展 = 3:7
- 紧张：放松 = 4:6
- 对话：描写 = 3:7

**禁忌**：
- 连续10章无冲突
- 连续5章全是战斗
- 连续3章全是感情戏

## 八、平台特色

| 平台 | 特点 | 建议 |
|------|------|------|
| 起点 | 老白文为主 | 节奏可以稍慢，注重世界观 |
| 飞卢 | 节奏快 | 前三章就要放爽点 |
| 番茄 | 脑洞文 | 创意要新颖 |
| 七猫 | 免费为主 | 爽点要密集 |
| 掌阅 | 付费为主 | 质量要求高，可写长 |
