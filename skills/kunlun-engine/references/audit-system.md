# 网文创作审计体系

> 48维审计体系：8道门禁 + 33维连续性审计 + 7维ICU

---

## 一、8道门禁 (Gate 1-8)

门禁是硬性检查项，任一未通过都会阻断章节发布。

### G1: 角色弧线门禁

| 检查项 | 标准 |
|--------|------|
| 角色成长 | 本章角色应有明确的成长或转变 |
| 心理变化 | 关键决策应有心理支撑 |
| 能力展现 | 异能/技能应有来源说明 |

**违规示例**：
- 主角突然学会新技能但未说明原因
- 角色态度180度转变无铺垫

### G2: 信息释放门禁

| 检查项 | 标准 |
|--------|------|
| 伏笔回收 | 之前埋下的伏笔应有交代 |
| 信息披露 | 重要信息应在合适时机披露 |
| 悬念设置 | 章末应有钩子吸引读者 |

**违规示例**：
- 重要物品出现但无来源说明
- 章末无悬念，读者可随时停止

### G3: 去AI味门禁

| 检查项 | 标准 |
|--------|------|
| 句式变化 | 避免模板化开头结尾 |
| 用词多样性 | 避免重复使用相同词汇 |
| 自然断句 | 避免机器般规整的句式 |

**AI常用句式检测**：
- "只见"、"但见"、"却说"
- "此时此刻"、"就在这一刻"
- "不由得"、"不禁"

### G4: 爽点间隔门禁

| 爽点类型 | 建议间隔 |
|----------|----------|
| 小爽点 | 每500-1000字 |
| 中爽点 | 每2000-3000字 |
| 大爽点 | 每5000-8000字 |

**违规示例**：
- 超过8000字无任何爽点
- 连续3个爽点过近造成疲劳

### G5: 多样性门禁

| 检查维度 | 最低要求 |
|----------|----------|
| 动词种类 | ≥50种/章 |
| 形容词种类 | ≥30种/章 |
| 句式变化 | ≥5种句式 |

### G6: 情绪节奏门禁

| 检查项 | 标准 |
|--------|------|
| 情绪曲线 | 应有起伏，不能全程平缓 |
| 高潮点 | 应有明显情绪高峰 |
| 缓冲段落 | 高潮后应有情绪缓冲 |

### G7: 对话自然门禁

| 检查项 | 标准 |
|--------|------|
| 口语化 | 对话应符合角色性格 |
| 信息量 | 对话应推动情节/揭示信息 |
| 比例控制 | 对话占比不超过40% |

### G8: 战斗描写门禁

| 检查项 | 标准 |
|--------|------|
| 动作清晰 | 战斗动作应有画面感 |
| 紧张感 | 应有节奏感和压迫感 |
| 结果合理 | 战斗结果应有铺垫 |

## 二、33维连续性审计

### 角色维度 (6维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| C1 | 姓名一致性 | 角色姓名全程一致 |
| C2 | 身份一致性 | 角色身份无矛盾 |
| C3 | 能力边界 | 能力使用前后一致 |
| C4 | 性格一致性 | 性格表现连贯 |
| C5 | 关系网络 | 人物关系无冲突 |
| C6 | 外貌一致性 | 外貌描述前后一致 |

### 情节维度 (6维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| P1 | 时间线 | 时间流逝合理 |
| P2 | 地点切换 | 地点转移有交代 |
| P3 | 因果关系 | 事件因果链完整 |
| P4 | 伏笔一致性 | 伏笔前后呼应 |
| P5 | 悬念逻辑 | 悬念解答合理 |
| P6 | 节奏把控 | 情节推进有节奏 |

### 信息维度 (5维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| I1 | 信息披露时机 | 信息在合适时机披露 |
| I2 | 信息准确性 | 重要信息无误 |
| I3 | 信息来源 | 信息来源明确 |
| I4 | 信息完整性 | 关键信息无缺失 |
| I5 | 信息冗余 | 无重复说明 |

### 逻辑维度 (6维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| L1 | 行为逻辑 | 角色行为合理 |
| L2 | 决策逻辑 | 决策有依据 |
| L3 | 战斗逻辑 | 战斗符合实力设定 |
| L4 | 情感逻辑 | 情感反应合理 |
| L5 | 社会逻辑 | 社会规则遵守 |
| L6 | 科学逻辑 | 无明显科学错误 |

### 情感维度 (5维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| E1 | 情感真实性 | 情感表达真实 |
| E2 | 情感深度 | 有情感层次 |
| E3 | 情感共鸣 | 能引发读者共鸣 |
| E4 | 情感引导 | 引导读者情绪 |
| E5 | 情感余韵 | 情感回味悠长 |

### AI痕迹维度 (5维)

| 编号 | 维度 | 检查内容 |
|------|------|----------|
| A1 | 句式模板 | 避免固定句式 |
| A2 | 用词习惯 | 避免AI高频词 |
| A3 | 标点规范 | 避免过于规整 |
| A4 | 段落结构 | 避免模板段落 |
| A5 | 逻辑连接 | 避免机械过渡 |

## 三、7维ICU检查

当章节通过33维审计但仍有质量问题时，启动ICU急救。

| ICU维度 | 说明 | 修复策略 |
|---------|------|----------|
| 完整性 | 章节结构完整 | 自动补充 |
| 连贯性 | 章节过渡自然 | LLM润色 |
| 一致性 | 设定无冲突 | 知识图谱校验 |
| 可读性 | 阅读体验流畅 | 句式优化 |
| 吸引力 | 钩子足够强 | 开头优化 |
| 爽感度 | 爽点密度合适 | 爽点注入 |
| 价值感 | 有阅读价值 | 主题强化 |

## 四、爽点类型定义

| 类型 | 说明 | 触发词 |
|------|------|--------|
| 逆转爽 | 反转逆境 | "没想到"、"反杀" |
| 成长爽 | 实力提升 | "突破"、"觉醒" |
| 打脸爽 | 当面反击 | "众人惊讶"、"啪啪打脸" |
| 收获爽 | 获得宝物 | "竟是..."、"机缘" |
| 情报爽 | 揭露秘密 | "原来..."、"真相是" |
| 情感爽 | 感情突破 | "心动"、"脸红" |
| 复仇爽 | 报仇雪恨 | "该死"、"清算" |
| 智斗爽 | 计谋成功 | "计中计"、"算无遗策" |

## 五、审计结果等级

| 等级 | 分数 | 含义 | 操作 |
|------|------|------|------|
| S | 95+ | 优秀 | 可直接发布 |
| A | 85-94 | 良好 | 微调后发布 |
| B | 70-84 | 合格 | 需修改后发布 |
| C | 60-69 | 较差 | 建议重写 |
| D | <60 | 很差 | 必须重写 |
