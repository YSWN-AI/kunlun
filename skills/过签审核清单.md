# 过签审核清单

> 用途: 章节完成后的质检清单，确保内容达到平台过签标准
> 使用方式: Auditor 审计门禁的补充参考，逐项检查

---

## 一、内容安全审核

### 政治敏感
- [ ] 无影射现实政治人物/事件
- [ ] 无涉及国家安全、领土完整的敏感表述
- [ ] 无对现行政策、制度的恶意丑化
- [ ] 架空世界观不与现实政治产生联想

### 社会价值
- [ ] 无宣扬暴力、色情、赌博等违法内容
- [ ] 无美化犯罪、教唆违法行为的描写
- [ ] 主角无极端反社会人格(虐杀/凌辱等)
- [ ] 无恶意挑动社会矛盾的表述

### 未成年人保护
- [ ] 未成年角色无不当亲密描写
- [ ] 校园场景无校园暴力美化
- [ ] 无诱导未成年人模仿危险行为

---

## 二、内容质量审核

### 原创性
- [ ] 无大段抄袭(单段>100字与已知作品高度相似即触发)
- [ ] 核心设定、金手指有原创性
- [ ] 剧情走向不与热门作品高度雷同
- [ ] 人物命名不与知名IP角色相同

### 连贯性
- [ ] 与前面章节无矛盾(时间线/人物状态/世界规则)
- [ ] 伏笔有埋设或揭示(不可埋完不挖)
- [ ] 人物行为符合已建立性格
- [ ] 战力体系无崩坏(越级挑战需合理解释)

### 水文检测
- [ ] 无超过500字的纯环境描写
- [ ] 无超过300字的内心独白(非关键情节)
- [ ] 战斗场景无注水(重复招式描述)
- [ ] 对话不是纯粹的日常寒暄

---

## 三、爽点密度审核

### 节奏要求
- [ ] 每3000字至少1个情绪起伏点
- [ ] 每章至少1个"读者想分享给朋友"的亮点
- [ ] 打脸场景有完整的挑衅→出手→震惊→连锁反应闭环
- [ ] 升级/突破场景有仪式感

### 钩子检查
- [ ] 章首300字有钩子
- [ ] 章末有强烈悬念或爽点收尾
- [ ] 钩子不重复使用同一模式(连续3章不用同一类钩子)

---

## 四、去AI味审核

### 语言特征
- [ ] 无"然而""因此""于是""总而言之"等AI高频连接词密集出现
- [ ] 无"在这个...的过程中""不难发现"等典型AI句式
- [ ] 对话无"你说得对""我明白了"等AI味回应
- [ ] 无大段排比句(3句以上并列)

### 节奏特征
- [ ] 段落长短参差(不可每段都在150-200字)
- [ ] 句子长度有变化(不可全是15-20字的中等句)
- [ ] 描述/对话/动作比例合理(不可通篇描述)

---

## 五、平台专项审核

### 起点过签标准
- [ ] 题材辨识度清晰
- [ ] 前3章完成黄金三章模板
- [ ] 有至少一个"这个设定有意思"的创新点
- [ ] 书名+简介+前三章形成完整吸引力闭环

### 番茄过签标准
- [ ] 每章读完率达到预期(内测数据)
- [ ] 前3章跳出率<50%
- [ ] 有明确的付费转化节点设计
- [ ] 适合短视频推广的名场面

### 七猫过签标准
- [ ] 开篇冲突立即呈现
- [ ] 金手指类型属于热门分类
- [ ] 章节长度稳定在2000-2500字
- [ ] 无长段落(单段落>300字即扣分)
