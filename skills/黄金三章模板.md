# 黄金三章模板

> 适用平台: 起点中文网 / 番茄小说 / 七猫
> 核心理念: 前3章决定80%的读者留存率，必须在最短篇幅内建立冲突-金手指-钩子闭环

---

## 第一章模板: 冲突建立

### 必须元素
- [ ] **开篇钩子**: 300字以内出现核心冲突或悬念
- [ ] **主角出场**: 明确主角身份(姓名/年龄/社会地位/当前困境)
- [ ] **困境展示**: 主角面临的具体问题(被欺压/被退婚/穷困/被追杀等)
- [ ] **世界基调**: 通过场景描写暗示世界观(都市修仙/赘婿/重生等)

### 结构建议
```
第0-300字: 钩子(一句话悬念或冲突场景)
第300-1000字: 主角现状(我在哪/我是谁/我有什么问题)
第1000-2000字: 冲突升级(有人挑衅/困境加重/危机逼近)
第2000-3000字: 章末钩子(悬念/金手指线索/复仇许诺)
```

### 禁忌
- 开篇大段世界观介绍
- 冗长的修炼体系说明(留到后面)
- 主角自怨自艾超过500字
- 章末没有悬念

---

## 第二章模板: 金手指觉醒

### 必须元素
- [ ] **金手指展现**: 明确特殊能力的来源、形式、限制
- [ ] **首次使用**: 金手指的第一次实际运用(让读者看到价值)
- [ ] **能力边界**: 至少暗示能力的局限(避免无敌流审美疲劳)
- [ ] **逆袭希望**: 给读者看到逆袭的可能性和路径

### 结构建议
```
第0-500字: 承接上章钩子，展示金手指觉醒过程
第500-1500字: 金手指首次使用(小试牛刀)
第1500-2000字: 主角认识到金手指价值，制定计划
第2000-3000字: 章末钩子(第一次大展身手的预告/新敌人出现)
```

### 禁忌
- 金手指能力描述过于模糊
- 首次使用就碾压一切(留升级空间)
- 完全没有使用限制
- 与主线剧情脱节

---

## 第三章模板: 首次打脸

### 必须元素
- [ ] **打脸场景**: 第一次让看不起主角的人震惊
- [ ] **实力展示**: 通过具体场景展示金手指带来的提升
- [ ] **身份伏笔**: 埋下主角真实身份的线索(可选，用于后期反转)
- [ ] **新冲突**: 引入下一个对手或更大的挑战

### 结构建议
```
第0-500字: 被挑衅/被看不起的场景
第500-1500字: 主角出手，打脸场景(详细描写反应)
第1500-2500字: 打脸后的连锁反应(他人震惊/新机会出现)
第2500-3000字: 章末钩子(更大挑战来临/新地图开启)
```

### 禁忌
- 打脸过程草草几笔带过
- 被打脸方反应不够详细(读者要看的就是这个)
- 打完脸后没有后续影响
- 主角得意忘形超过300字

---

## 通用黄金三章检查清单

| 检查项 | 第一章 | 第二章 | 第三章 |
|---|---|---|---|
| 字数2000-3000 | ☐ | ☐ | ☐ |
| 章首300字内有钩子 | ☐ | ☐ | ☐ |
| 章末有悬念/钩子 | ☐ | ☐ | ☐ |
| 对话占比≥20% | ☐ | ☐ | ☐ |
| 爽点/情绪起伏≥1次 | ☐ | ☐ | ☐ |
| 无大段世界观介绍 | ☐ | ☐ | ☐ |

---

## 签约向优化

### 起点
- 额外要求: 前三章必须体现题材辨识度
- 加分项: 包含一个"这个题材我没见过"的创新点

### 番茄
- 额外要求: 每章结束必须让读者想点"下一章"
- 加分项: 第三章出现第一个付费意愿点(读者愿意为这个情节付费)

### 七猫
- 额外要求: 开场300字必须直接进入冲突(不可有环境描写)
- 加分项: 主角人设足够鲜明，读者能一句话总结
