# 口语化改写规则

> 目标: 将AI味的书面语言改写为符合网文读者预期的口语化表达
> 核心理念: 网文不是作文，读者要的是"像朋友讲故事"的阅读体验

---

## 一、连接词替换规则

### 替换表

| AI味连接词 | 替换为 | 示例 |
|---|---|---|
| 然而 | 可…/不过/但偏偏 | "然而他没想到" → "可偏偏他没想到" |
| 因此 | 所以/于是乎/这下 | "因此他决定出手" → "这下不出手不行了" |
| 于是 | 接着/然后/便 | "于是他走上前" → "他走上前" |
| 与此同时 | 另一边/这时候/此刻 | "与此同时，在宗门" → "此刻，宗门内" |
| 总而言之 | 说白了/一句话 | "总而言之，他很强" → "说白了，就是强" |
| 不仅如此 | 更要命的是/更绝的是 | "不仅如此，他还" → "更要命的是，他还" |
| 显而易见 | 明摆着/谁都看得出来 | "显而易见他的实力" → "明摆着的实力" |
| 毋庸置疑 | 没得说/毫无疑问 | "毋庸置疑他是最强的" → "没得说，最强就是他" |

### 规则
1. 每3000字内「然而」出现不超过2次
2. 「因此」「于是」二选一，不重复使用
3. 「与此同时」全部替换为具体场景切换词

## 二、句式结构改写

### 被字句→主动句
```
AI味: 他被一股强大的力量击飞了出去
口語: 一股巨力轰来，他整个人倒飞出去
```

### 长定语→短句拆分
```
AI味: 作为一个在修真界摸爬滚打了三百年的老怪物，他深知
口語: 修真界摸爬滚打三百年，什么场面没见过。他太清楚了——
```

### 书面倒装→正常语序
```
AI味: 映入他眼帘的是一座巍峨的宫殿
口語: 一座巍峨宫殿，赫然立在眼前
```

## 三、对话改写

### AI味对话特征
- 过于客套: "感谢阁下出手相助"
- 过度解释: "我之所以这么做是因为..."
- 情感表达生硬: "我感到非常愤怒"
- 对称问答: 你来我往像AI对话

### 改写原则
```
1. 角色对话要符合身份:
   - 底层散修: 粗俗直接，可能带脏话
   - 宗门弟子: 半文言或带称呼，但不能过于书面
   - 反派: 嚣张但有特色(不能千篇一律的"哈哈哈哈")
   
2. 对话节奏:
   - 冲突对话: 短句交锋(2-3回合后一方被打断/动手)
   - 信息对话: 穿插动作和环境描写(避免纯对话)
   - 情感对话: 适当留白(说一半、被打断、转移话题)
   
3. 禁用AI味回应:
   ❌ "你说得对"
   ❌ "我明白了"
   ❌ "原来如此"
   ❌ "这倒是个问题"
   ✅ "行" / "懂了" / "啧" / 直接沉默或转移动作
```

## 四、描写改写

### 外貌描写
```
AI味: 她有着一头乌黑亮丽的长发，眼睛如同星辰般明亮
口語: 黑发如瀑，眸似星辰
       (网文外貌尽量用短句+比喻，不求全求特点)
```

### 战斗描写
```
AI味: 他运起全身灵力，一掌拍出，掌风呼啸，气势惊人
口語: 灵力暴涌。一掌拍出——
      轰！
      掌风过处，地面炸裂。
      (短句+拟声词+换行留白=速度感)
```

### 环境描写
```
原则: 环境描写不超过3句，且必须服务于当前情节
- 战斗场景: 突出对战斗有影响的环境因素
- 日常场景: 1-2句建立氛围即可
- 转场: 用地名/标志物一笔带过
```

## 五、节奏控制

### 快节奏场景(战斗/打脸/逃亡)
- 句子长度: 3-8字为主
- 段落长度: 1-3行为主
- 描述比例: <20%
- 拟声词: 轰/砰/刷/嗖 等高频使用

### 中节奏场景(日常/修炼/谋划)
- 句子长度: 8-15字为主
- 段落长度: 3-6行为主
- 描述比例: 30-50%
- 对话比例: 40-60%

### 慢节奏场景(情感/回忆/铺垫)
- 句子长度: 10-20字为主
- 段落长度: 2-5行为主
- 描述比例: 40-60%
- 内心独白可适当增加(不超过200字)

## 六、自查清单

每章完成后对照检查:
- [ ] 「然而」出现≤2次
- [ ] 「因此」出现≤2次
- [ ] 无超过150字的单句
- [ ] 无超过300字的单段落
- [ ] 对话占比≥25%(战斗章节除外)
- [ ] 拟声词使用≥3次(战斗章节)
- [ ] 无连续3段纯描述
- [ ] 有人称代词多样化(不连续用"他"开头)
