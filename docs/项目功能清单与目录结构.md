# 昆仑创作引擎 — 项目功能清单与目录结构

> **版本**: v0.4.0 | **核心理念**: Vibe Writing（直觉式AI创作）  
> **代码量**: ~81,000 行 Python（398 .py, 72 子包）+ 前端（31 .vue/.ts） | **测试**: 840 个  
> **最后更新**: 2026-06-14

---

## 一、功能全景图

```
┌─────────────────────────────────────────────────────────┐
│                      前端 UI (Vue 3)                      │
│  创作中心 │ 作品管理 │ 世界设定 │ 审计中心 │ 设置            │
│  (简洁模式默认 5 面板，高级模式 14 面板)                    │
├─────────────────────────────────────────────────────────┤
│                    REST API (FastAPI)                     │
│  /api/v1 (162 路由) + /api/v2 (155 路由) = 328 总路由     │
├─────────────────────────────────────────────────────────┤
│                    CLI (python kunlun_cli.py)             │
│  up │ down │ doctor │ status │ write │ export │ ...       │
├─────────────────────────────────────────────────────────┤
│                     核心管线 (17 步)                       │
│  蓝图 → 初稿 → 审计(53维) → 修订 → 反思 → 发布             │
├─────────────────────────────────────────────────────────┤
│                 多 Agent 体系 (10 Agent)                   │
│  主编 │ 架构师 │ 写手 │ 审计员 │ 编辑 │ 社会学家 │ ...       │
├──────────────────┬──────────────────────────────────────┤
│   知识图谱 (KG)   │        抽卡引擎 (Gacha)                │
│  Neo4j/SQLite    │  3级级联 │ 模型路由 │ 熔断器             │
├──────────────────┴──────────────────────────────────────┤
│              基础设施 (Infrastructure)                    │
│  Docker(Neo4j/Redis/Qdrant/NATS) │ 降级到 SQLite 内置     │
└─────────────────────────────────────────────────────────┘
```

## 三、核心功能详解

### 3.1 写作管线 — 17 步全自动生成

```
  [输入] 章节编号 + 大纲
    │
    ├─ 步骤1: 蓝图生成       → 章节大纲、情绪曲线、伏笔安置
    ├─ 步骤2: 初稿生成       → 多模型抽卡生成正文
    ├─ 步骤3: 情报同步       → 前情提要 + KG 注入
    ├─ 步骤4: KG 更新        → 角色/世界观/伏笔 存入知识图谱
    ├─ 步骤5: ICU 自纠       → 语法/逻辑/事实错误修正
    ├─ 步骤6: 审计评估       → 53维质量评估
    ├─ 步骤7: 质量检查       → 通过率≥80% 才继续
    ├─ 步骤8: 社会推演       → 44维社会背景推演
    ├─ 步骤9: 真相+指纹      → 伏笔收束 + 文风指纹
    ├─ 步骤10: 风格漂移      → 检测前后文风变化
    ├─ 步骤11: 修订循环      → 不达标则重新生成(最多3轮)
    ├─ 步骤12: 润色          → 文笔打磨
    ├─ 步骤13: 学习记录      → LLM→参数优化 反馈
    ├─ 步骤14: 后写验证      → 输出合约验证
    ├─ 步骤15: 后反思        → 自我评估报告
    ├─ 步骤16: 版本快照      → 保存当前版本
    └─ 步骤17: 发布          → 格式化输出 + 同步
```

### 3.2 多 Agent 体系 — 10 角色协作

| Agent | 模块 | 职责 |
|-------|------|------|
| **主编** (Editor) | `agents/editor.py` | 意图分类 + 全流程编排 |

| **写手** (Writer) | `agents/writer.py` | 正文初稿生成 (多模型抽卡) |

| **观察员** (Observer) | `agents/observer.py` | 写作质量持续监控 |

### 3.3 审计系统 — 53 维 + 8 门禁

**6 维度分组**：

| 组 | 维度 | 核心指标 |
|----|------|----------|
| A: 角色 | 13维 | 辨识度、一致性、成长弧、对话自然度 |
| B: 情节 | 10维 | 冲突强度、因果链、信息密度、伏笔 |
| C: 结构 | 8维 | 章节完整度、钩子强度、节奏感 |
| D: 风格 | 10维 | 句式多样性、AI痕迹、套话、文笔 |
| E: 读者 | 7维 | 代入感、情感冲击、悬念、快感周期 |
| F: AI特征 | 5维 | 水印、重复模式、幻觉、不一致 |

**8 道门禁** (G1-G8)：剧情弧线 → 信息密度 → AI痕迹 → 快感周期 → 快感多样性 → 情感校验 → 对话校验 → 战斗场面

**本地模式降级**：自用模式下自动降为 15 维核心审计，跳过 Tier 3 级联评估。

### 3.4 知识图谱 — 29 节点 + 57 关系

**本体类型**：Character / World / Event / Faction / Location / Item / Skill / Plot / ChekhovGun / Chapter / Book / Timeline / EmotionCurve / Arc / ...

**仓储模式**：
- **Neo4j** 图仓储（图查询 Cypher）
- **Qdrant** 向量仓储（语义检索）
- **SQLite** 降级仓储（图+全文检索，零外部依赖）

### 3.5 抽卡引擎 — 3 级级联 + 熔断器

```
Tier 1: 廉价模型 (deepseek-chat / qwen3)
  ↓ 不达标
Tier 2: 中等模型 (deepseek-chat × 参数变异)  
  ↓ 不达标
Tier 3: 顶级模型 (deepseek-reasoner / claude-sonnet)
```

- **模型路由表**：TaskType → 模型优先级映射
- **熔断器**：30秒恢复窗口 + 最小3次调用前触发
- **Key 轮换器**：多 API Key 自动切换
