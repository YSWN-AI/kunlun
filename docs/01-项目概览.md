## 项目定位

**昆仑引擎 = AI 网文创作伙伴。** 核心理念是 **Vibe Writing** — 不说参数，只说感受。用户通过自然对话与AI深度协作，AI自动完成开书、世界观构建、角色设计、章节创作、质量把控到导出的全流程。

系统将网文创作拆解为**六大驱动力**协同运作：
- **金手指驱动** → 爽点引擎(12种) + 疲劳度分析
- **情节驱动** → 伏笔全生命周期 + 钩子管理 + 情感曲线
- **人物驱动** → 角色弧线(7维) + 状态机 + 关系图谱
- **冲突驱动** → 冲突管理器 + TensionManager + 张力热力图
- **情绪驱动** → 情绪一致性校验 + 情感线追踪
- **Vibe Writing** → 14种氛围类型 + 场景氛围标注 + 氛围过渡建议

## 安装

```bash
python -m venv venv && source venv/Scripts/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # 然后编辑 .env 填入 API Key
uvicorn kunlun.api.main:app --host 127.0.0.1 --port 8000 --reload
```

首次启动会自动初始化 SQLite 数据库，无需手动建表。

## 17步创作流水线（六大驱动力全覆盖）

```
KG快照 → Architect蓝图 → Society社会推演 → Writer抽卡生成
  → 冲突追踪 → Vibe氛围追踪 → 后写验证(零LLM)
  → Auditor审计(33维/8门禁) → [修订循环 ≤3轮]
  → ICU 7维检查 → 质量看板(可执行结果) → StyleEngineer润色
  → KG更新 + 爽点记录 → TruthFile同步 → 反思学习
```

用户也可通过 **Vibe Writing 总调度** 一句话完成全流程：
- 说"写一本玄幻小说" → AI自动开书、建世界观、设角色
- 说"写第一章" → AI创作、保存、报告
- 说"太慢了加快节奏" → AI自动修改文件
- 说"检查质量" → AI运行审计门禁
- 说"导出全书" → AI合并所有章节生成完整文件

## Agent 体系（11个）

| Agent | 职责 |
|-------|------|
| **VibeOrchestrator** ★ | 总调度（至高Agent）——Vibe Writing入口，你说一句话它完成一切（开书→创作→导出） |
| **EditorInChief** | 主编总调度——自然语言理解 → 分派任务给专业Agent（8步对话管线） |
| **Makefile** | 流水线编排——13步→17步状态机管理 + 同步/异步双模式 + 自适应跳过 |
| **Architect** | 建筑师——KG快照+RAG检索 → 生成章节蓝图（场景/情绪/爽点/冲突/氛围排布） |
| **Writer** | 写手——多模型抽卡生成正文 + 审计修订 + Vibe prompt注入 |
| **Auditor** | 审计员——委托8门禁+33维审计，零LLM纯规则 |
| **Sociologist** | 社会学家——44维社会深层推演（v1→v9迭代），每章RAG召回 |
| **StyleEngineer** | 润色师——去AI味 + 文风指纹注入 + Vibe氛围引擎 |
| **ConflictEngine** ★ | 冲突追踪器——Conflict数据模型 + TensionManager + 冲突热力图 |
| **Publisher** | 发布员——章节落盘 + 多格式导出 |
| **MessageBus** | 消息总线——Agent间通信（NATS/InProcess双模式） |

## 核心子系统

### Gacha 抽卡引擎
多模型并行生成，4种模式（单模型/3并行/2廉价级联/5终极段落混搭），9维纯统计评分（钩子/爽点/去AI/情绪/信息/节奏/角色/风格/对话）。无 LLM 参与评分。

### 48维审计体系
- **33维**连续性审计（6组：A角色/B物品/C伏笔/D叙事/E情绪/F AI痕迹），纯规则
- **8门禁**规则门禁（弧线/信息释放/去AI/爽点间隔/多样性/情绪/对话/战斗），纯规则
- **7维ICU**：爽点/情绪/信息/节奏/钩子/OOC/对话，LLM 自动修复

### 44维社会推演
v1→v9 迭代（GENESIS→EPILOGUE），覆盖经济/法律/文化/历史/权力/技术/生态/黑市/哲学等。开书时1次全量推演→向量库存，每章RAG召回+单次轻量剧情推演。

### 四层知识图谱
Neo4j(图主存) → SQLite(降级) | Qdrant(向量/BGE→hash降级) | SQLite FTS5(全文)，优雅降级贯穿始终。

### 50维偏好学习
EMA 更新 + 遗忘衰减 + 置信度加权，7类事件驱动（章完成/审计通过/审计失败/修订/作者反馈/读者反馈/风格修改），偏好注入 Writer/Architect prompt。

### 自进化闭环
写后反思（reflector）→ 规则提取 → 技能生成（evolve）→ 注入系统 prompt，形成全自动改进循环。
