# 昆仑创作引擎 — 工作台优化调研报告与重设计方案

> 调研日期：2026-09-04
> 调研范围：8款AI网文/写作工具 + 3款AI IDE + 2款传统IDE
> 目标：参考行业最佳实践，优化昆仑创作引擎工作台设计

---

## 一、调研概述

本次调研覆盖三大类产品：

| 类别 | 产品 | 核心价值 |
|------|------|----------|
| AI网文创作工具 | 灵犀速写、白梦写作、星月写作、彩云小梦 | AI辅助写作全流程 |
| 平台作家工具 | 番茄作家助手、起点作家助手 | 创作管理+数据面板+发布 |
| 通用AI写作 | 秘塔写作猫、get智能写作 | 模板生成+校对改写 |
| AI IDE | TRAE、Cursor、Windsurf | AI辅助编程的交互范式 |
| 传统IDE | VS Code、JetBrains | 工作台布局与效率设计 |

核心结论：**昆仑在技术深度（53维审计、知识图谱、多模型抽卡、Agent体系）上领先行业，但在产品交互体验和用户可见性上存在明显差距。** 需要将技术能力转化为用户可感知的界面交互。

## 三、核心设计亮点分析

### 3.1 白梦写作 — 编辑器体验创新

1. **正文设定高亮联动**：角色名和Bio信息在正文中自动彩色高亮，点击弹出信息卡并定位。这是知识图谱可视化的最佳交互形态。
2. **彩色标注审稿流**：用户自定义颜色含义（黄色=补细节，蓝色=加内心活动），先全文标注不打断思路，后期通过导航条统一跳转修改。审稿效率翻倍。
3. **AI消痕体系**：消痕模板+高频词消痕+降AI率工具箱，专门针对平台AI检测优化，是网文作者核心痛点。
4. **经典三栏布局**：左侧文件树（分卷/章节/角色/设定）+ 中间编辑器 + 右侧AI交互，符合创作者心智模型。

### 3.2 星月写作 — 方法论产品化

1. **本章10条卡**：每章10条核心剧情点驱动正文生成，确保AI不跑偏，是"细纲流"的核心机制。
2. **钢章续写**：一次生成十章章纲，可反复抽卡选择，解决卡文难题。
3. **情绪走向滑杆**：续写时通过滑杆调节情绪基调，交互新颖且实用。
4. **脑洞生成器**：输入灵感后自动分析爽点、规避抄袭，配合"手搓细纲流"形成完整创作方法论。
5. **AI拆书"三幕七节点"**：输入书名10秒输出情节拆解+爆款公式，拆书深度结构化。

### 3.3 灵犀速写 — 平台化生态

1. **多智能体协同**：灵犀娘（助手）、墨璃（执笔）、夜澜（主编）多角色协同，智能体体系最完善。
2. **可视化工作流编排**：拖拽式编排创作步骤，模板市场一键执行，执行记录可回溯。
3. **短剧改编工作台**：小说一键改编短剧，自动分镜与台词生成，跨媒体能力独树一帜。
4. **自定义Skills生态**：用户可创建、修改、打包、分享自定义技能。

### 3.4 番茄作家助手 — 数据面板标杆

1. **X万字读完率**：作为核心质量指标，5档位曲线对比同段位作品。
2. **6维流量来源拆解**：清晰展示流量从哪里来。
3. **收益双轨透明化**：广告收益+订阅收益分别展示。

### 3.5 AI IDE — 交互范式革命

1. **行内编辑+内联diff**（Cursor Ctrl+K）：AI修改结果直接在原文中展示差异，用户逐处确认，是最自然的人机协作方式。
2. **@上下文引用**：用户用`@`精确指定AI需要参考的资料，比自动上下文更可控。
3. **命令面板**：键盘流用户的核心入口，所有操作可搜索可执行。
4. **Checkpoint快照**（Windsurf）：AI操作前自动备份，消除"改坏了怎么办"的顾虑。
5. **多文件Agent**（Cursor Composer）：一次指令跨多个文件批量处理，适合大规模一致性修改。

## 五、昆仑工作台重设计方案

### 5.1 整体布局：IDE式五区结构

```
┌─────────────────────────────────────────────────────────┐
│  顶部标题栏（项目名 + 模型选择 + 保存/导出 + 服务状态）      │
├────┬──────────┬──────────────────────────┬───────────────┤
│    │          │  标签页栏 [章1][章2][大纲] │ [分屏][设置] │
│ 活 │  侧边栏   ├──────────────────────────┤               │
│ 动 │ (240px)  │                          │               │
│ 栏 │          │      主编辑区             │               │
│ 48 │  章节树   │    (正文编辑器)           │               │
│ px │  人物     │    - 实时字数             │               │
│    │  世界观   │    - 选中AI浮层           │               │
│    │  大纲     │    - 设定高亮联动         │               │
│    │          │                          │               │
├────┴──────────┴──────────────────────────┴───────────────┤
│  底部面板（可折叠）：[AI对话] [审校结果] [输出日志]          │
│  - AI对话：Vibe Writing聊天，总调度/Vibe模式切换            │
│  - 审校结果：六维质量/AI率/辩论审校结果展示                  │
├─────────────────────────────────────────────────────────┤
│  状态栏：书籍名 | 章节 | 行:列 | 字数 | 质量分 | 模型 | 状态 │
└─────────────────────────────────────────────────────────┘
```

### 5.2 功能模块重新组织

| 区域 | 模块 | 说明 |
|------|------|------|
| **活动栏** | 资源管理器/搜索/大纲/人物/世界观/AI助手/质量/设置 | 图标导航，切换侧边栏视图 |
| **侧边栏** | 章节树（分卷→章节）、人物列表、世界观词条、大纲 | 项目资源管理，点击在编辑区打开 |
| **主编辑区** | 正文编辑器（多标签+分屏）、欢迎页 | 核心创作区域，选中文字触发AI浮层 |
| **底部面板** | AI对话（创作）、审校结果（六维/AI率/辩论）、输出日志 | 辅助面板，不打断创作流 |
| **状态栏** | 实时字数、质量分、光标位置、模型、保存状态 | 信息一览，点击可触发操作 |
| **命令面板** | 所有操作的统一搜索入口 | Ctrl+Shift+P唤起 |

### 5.3 交互流程优化：创作→审校→修改闭环

```
创作阶段                     审校阶段                     修改阶段
┌──────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 底部AI对话    │    │ 选中正文→右键     │    │ 审校结果自动标注   │
│ 生成大纲/细纲 │───▶│ →六维质量/AI率   │───▶│ 问题区域(彩色)     │
│              │    │ →辩论审校         │    │ 导航条批量跳转     │
│ 正文编辑器    │    │                  │    │ 行内AI编辑(diff)   │
│ 手动+AI续写   │    │ 底部审校结果Tab   │    │ 逐处接受/拒绝      │
│ @角色引用     │    │ 评分+问题列表     │    │ Checkpoint可回滚   │
└──────────────┘    └──────────────────┘    └──────────────────┘
```

关键改进：
1. **审校不打断创作**：审校结果在底部面板展示，正文中标注问题，无需切换全屏面板
2. **修改闭环**：点击审校问题→自动定位到正文位置→行内AI编辑→diff确认
3. **上下文感知**：AI对话自动加载当前章节、相关角色、世界观设定
4. **操作可回滚**：每次AI修改前自动创建Checkpoint

## 六、昆仑差异化优势（应保持强化）

1. **53维质量审计 + 8门禁**：行业最深的质量评估体系，应产品化为可视化标注
2. **四层知识图谱**：唯一具备知识图谱的网文工具，应通过高亮联动让用户感知
3. **多模型抽卡引擎**：4模式/9维评分，应升级为任务级模型路由
4. **Vibe Writing对话式创作**：已有的对话式创作，应常驻底部面板
5. **全管线自动写作**：pipeline体系，应可视化编排
6. **版本管理与回滚**：versions模块，应增强为Checkpoint快照
