# AI网文/写作工具产品设计调研报告

> 调研日期：2026-09-04
> 调研对象：彩云小梦、AI写作猫（秘塔写作猫）、get智能写作、番茄作家助手、起点作家助手
> 调研目的：为昆仑创作引擎（kunlun）的产品设计提供竞品参考与可借鉴功能清单

## 一、彩云小梦

### 1.1 产品定位与目标用户

- **定位**：彩云科技推出的AI小说创作与角色扮演平台，主打"人机共创"模式，既是AI续写工具，也是虚拟角色互动社区。
- **目标用户**：网文作者（轻量级辅助创作）、角色扮演爱好者、互动故事创作者、AI写作尝鲜用户。
- **规模**：超过1500万用户创作的虚拟角色，国内版日产4亿字，基于自研V2/V3大模型（DCFormer架构）。

### 1.2 工作台整体布局

- **移动端App为主**，核心界面为"创作页"：上方为文本编辑区，下方/侧边为AI操作按钮（"AI小梦来帮写"）。
- **世界广场**：独立Tab，用户可浏览、加入他人创建的世界观，或分享自己的世界。
- **角色详情页**：展示虚拟角色人设，提供聊天、语音通话入口。
- 整体偏"轻创作+互动"，无传统网文工具的大纲/章节/数据等重型模块。

### 1.3 核心功能模块清单

| 模块 | 功能说明 |
|------|----------|
| AI续写 | 输入1-1000字开头，AI自动续写后续故事 |
| 平行世界 | 一次生成3条不同故事走向，可选择继续或换一批 |
| 模型切换 | 标准、言情、玄幻、纯爱等多种风格模型，可自定义续写字数 |
| 角色卡/虚拟角色 | 创建并管理虚拟角色，支持人设编码 |
| 角色扮演聊天 | 与AI角色进行对话互动，角色会"记住"交流历史 |
| 语音通话 | 与虚拟角色语音通话，支持通话录音回听 |
| 世界广场 | 浏览/加入/分享世界观设定 |
| 创作管理 | 保存创作内容，多作品管理 |

### 1.4 AI交互模式

- **按钮触发式续写**：在文本中点击"AI小梦来帮写"，AI基于上下文续写。
- **多候选分支**：每次返回3条不同走向（平行世界），用户选择后继续，形成分支叙事。
- **角色对话式**：选择角色后进入聊天界面，AI以角色身份回应，支持语音。
- **风格模型路由**：用户可切换不同题材模型，影响续写风格。
- 无复杂的Agent编排或多步管线，属于"单步生成+人工选择"的轻量交互。

### 1.5 数据统计与可视化

- **无作家后台数据面板**：彩云小梦定位为创作工具而非发布平台，不提供稿费、订阅、留存等商业数据。
- 仅有基础的创作内容管理（作品列表、字数），无趋势图、环比等可视化。

### 1.6 章节管理与发布流程

- **无传统章节管理**：不区分卷/章结构，以"创作片段"形式组织内容。
- **无发布流程**：内容保存在平台内，可分享到世界广场，但不直接对接小说发布渠道。
- 与喜马拉雅合作推出AI有声小说，属于内容二次分发，非作者自助发布。

### 1.7 特色功能

1. **平行世界分支续写**：3条故事走向的设计是其核心差异化，将"抽卡"理念引入写作。
2. **虚拟角色生态**：1500万+角色形成UGC社区，角色可被多人使用和互动。
3. **语音通话**：AI角色语音交互，增强情感连接。
4. **世界广场**：世界观共享机制，降低创作门槛。

### 1.8 与平台生态的结合方式

- 独立平台，不隶属于任何小说阅读站。
- 与喜马拉雅合作AI有声内容分发。
- 角色/世界数据形成自有UGC生态闭环。

## 二、AI写作猫（秘塔写作猫）

> 注：市场上存在两款"写作猫"——秘塔写作猫（xiezuocat.com，通用AI写作平台）和小说专用"写作猫"（xiezuomao，已较少更新）。本节以功能更完善、AI能力更强的**秘塔写作猫**为主，兼述小说专用写作猫的特色。

### 2.1 产品定位与目标用户

- **秘塔写作猫定位**：AI Native内容创作平台，集AI写作、多人协作、文本校对、改写润色、自动配图为一体。
- **目标用户**：自媒体创作者、职场文案、学生论文写作者、内容运营人员。
- **小说专用写作猫定位**：专业小说创作软件，支持大纲/角色/世界观管理，面向中长篇小说作者。

### 2.2 工作台整体布局

- **Web端为主**：左侧文档列表/模板库，中央为富文本编辑器，右侧/顶部为AI功能面板。
- **编辑器内集成AI**：右上角"方块图标"可随时召唤AI模板列表，AI功能内嵌于写作流程。
- 小说专用写作猫为桌面端（Windows/Mac）+移动端，左侧作品/章节树，中央编辑区。

### 2.3 核心功能模块清单

| 模块 | 功能说明 |
|------|----------|
| AI写作模板 | 报告、营销文案、头脑风暴等场景模板，按步骤确认摘要和大纲后生成全文 |
| 交互式续写 | 编辑器内随时召唤AI续写 |
| 文本校对 | 独有NLP纠错，错别字、语病、成语使用检测 |
| 改写润色 | 一键改写，支持多次修改 |
| 中英翻译 | 中英文互译 |
| 摘要生成 | AI提炼内容重点生成摘要 |
| 全文检测 | 内容质量/原创性检测 |
| 自动配图 | 为文章自动配图 |
| 多人协作 | 团队协同编辑 |
| （小说专用）大纲系统 | 主题大纲、情节大纲、角色大纲 |
| （小说专用）时光机 | 版本回退，找回编辑痕迹 |
| （小说专用）角色标签 | 角色设定与出场统计 |
| （小说专用）设定关联 | 章节可关联世界观、角色、道具设定 |
| （小说专用）导入导出 | 多格式导入导出 |

### 2.4 AI交互模式

- **模板驱动式**：选择模板→填写关键词→AI生成大纲→确认→生成全文，分步式引导。
- **编辑器内召唤式**：写作过程中随时点击AI按钮进行续写/改写/摘要。
- **指令贯彻式**：用户输入创作要求和指令，AI在编辑环境中执行。
- 小说专用写作猫的AI能力较弱，以结构化管理为主。

### 2.5 数据统计与可视化

- **无网文商业数据**：不提供稿费、订阅、留存等数据。
- 秘塔写作猫有文档管理和协作记录，但无创作趋势分析。
- 小说专用写作猫提供字数统计，但无可视化图表。

### 2.6 章节管理与发布流程

- **秘塔写作猫**：以"文档"为单位管理，无章节/卷结构，无发布流程。
- **小说专用写作猫**：支持作品→章节的层级管理，自动保存、云同步；但无直接对接发布平台的功能，需导出后手动发布。

### 2.7 特色功能

1. **NLP纠错引擎**：秘塔自研，中文文本校对能力是核心优势。
2. **AI模板库**：覆盖多场景的结构化生成模板。
3. **时光机（小说专用）**：无限版本回退，对长篇创作很有价值。
4. **设定关联（小说专用）**：章节与世界观/角色/道具的关联管理。

### 2.8 与平台生态的结合方式

- 独立SaaS工具，不隶属于小说平台。
- 秘塔写作猫面向通用内容创作，无网文生态绑定。
- 小说专用写作猫为纯本地/云端工具，输出需手动导入发布平台。

## 三、get智能写作

### 3.1 产品定位与目标用户

- **定位**：字语智能（深圳）旗下AI写作平台，官网 getgetai.com，主打"用AI加速写作"，面向新媒体内容运营。
- **目标用户**：内容运营、新媒体运营、自媒体写作者、营销文案人员。
- **slogan**：减少80%的重复脑力劳动，释放大脑，专注创作。

### 3.2 工作台整体布局

- **Web端**：首页输入主题进入创作页面。
- **创作页布局**：中央为编辑器，左侧展示从搜索引擎抓取的同主题相关文章（素材参考区），顶部/侧边为AI功能入口。
- 整体为"素材参考+AI创作"双栏布局。

### 3.3 核心功能模块清单

| 模块 | 功能说明 |
|------|----------|
| AI模板成文 | 输入关键词，基于10w+文章模板生成完整文章 |
| AI热点成文 | 输入热点话题，AI自动生成热点内容 |
| 智能改写 | 已有内容一键改写，二次创作 |
| 智能续写 | 针对关键词、句、段落扩写 |
| 智能取标题 | AI推荐标题 |
| 智能摘要 | 提炼内容重点 |
| 全文检测 | 内容质量检测，标记异常 |
| 中英翻译 | 中英文互译 |
| 精准文章素材 | 同主题相关文章抓取与推荐 |
| 自定义模块 | 用户可自定义编辑专属创作模块 |
| 区块链数据资产 | 优质prompt和数据成为用户资产，可分享互通 |

### 3.4 AI交互模式

- **主题输入式**：首页输入主题→直接进入创作，AI自动生成初稿。
- **模板选择式**：从大量创作模块中选择场景，输入关键词生成。
- **素材参考式**：左侧实时展示同主题文章，供用户参考借鉴。
- **二次创作式**：粘贴已有内容，进行改写/续写/摘要。
- 交互偏"批量产出"，适合新媒体高频内容生产。

### 3.5 数据统计与可视化

- **无网文商业数据**：不涉及稿费、订阅等。
- 无创作趋势分析，以单次内容产出为核心。

### 3.6 章节管理与发布流程

- **无章节管理**：以单篇文章为单位，无长篇结构管理。
- **无发布流程**：生成内容后复制导出，无平台对接。

### 3.7 特色功能

1. **热点成文**：紧跟热点话题自动生成内容，是新媒体运营的刚需功能。
2. **10w+模板库**：大量爆款文章模板，降低创作门槛。
3. **左侧素材参考栏**：自动抓取同主题文章，边写边参考。
4. **自定义创作模块**：用户可打造专属AI模块。
5. **区块链数据资产**：将prompt和数据确权为用户资产，较为创新。

### 3.8 与平台生态的结合方式

- 独立SaaS平台，无小说平台生态绑定。
- 通过微信公众号（GETGETAI）运营用户社群。
- 定位为通用内容生产工具，非网文专用。

## 四、番茄作家助手

### 4.1 产品定位与目标用户

- **定位**：番茄小说（字节跳动旗下）官方作家工具，是作家创作、管理、数据查看、收益提现的一站式平台。
- **目标用户**：番茄小说签约/未签约作家，覆盖从新手到大神的全层级作者。
- **平台模式**：免费阅读+广告分成，依托字节跳动大数据智能分发。

### 4.2 工作台整体布局

#### App端（底部4 Tab）

| Tab | 内容 |
|-----|------|
| **作品** | 作品卡片列表（左右滑动切换）、创建新书、章节管理、草稿箱 |
| **数据** | 每日数据、每日收益、每月稿费 |
| **消息** | 审核结果、签约进度、互动消息、活动公告、作家课堂、作家反馈 |
| **我的** | 个人信息、实名认证、帮助中心、意见反馈、设置 |

#### Web端作家后台（左侧导航8模块）

1. **工作台** — 首页总览
2. **作品管理** — 书籍/章节/草稿/签约管理
3. **番茄数据** — 作品数据统计
4. **收益分析** — 收益与稿费
5. **互动管理** — 评论/读者互动
6. **头条推荐** — 头条渠道推荐管理
7. **福利管理** — 全勤奖等福利申请
8. **作者公告** — 平台通知

#### 工作台首页5大模块

- **作家信息**：创作天数、粉丝数、累计创作字数
- **我的作品**：最近更新作品快捷入口
- **码字日历**：按作品切换，查看每日更新情况，含请假功能
- **活动中心**：征文/爆更活动入口
- **公告**：平台最新资讯

### 4.3 核心功能模块清单

| 模块 | 功能说明 |
|------|----------|
| 作品创建 | "+新书"创建作品，选择分类 |
| 章节编辑器 | 正文编辑、护眼/黑暗模式、标题格式切换（第X章/纯标题） |
| 草稿箱 | 不限字数保存，展示每篇草稿字数 |
| 定时发表 | 预设发布时间，可修改 |
| 章节管理 | 章节状态可视化、删除与修改 |
| 作品信息管理 | 书名/简介修改、签约后置顶/隐藏、未签约可删除/申请完结 |
| 签约管理 | 合同下载、签约关键时间节点、进度追踪 |
| 福利申请 | 全勤奖等福利申请入口，审核通过后随稿费发放 |
| 码字日历 | 每日更新记录、请假功能 |
| 数据统计 | 数据概览/质量分析/流量分析（详见4.5） |
| 收益分析 | 每日收益/每月稿费/礼物收益（详见4.5） |
| 互动管理 | 读者评论、催更、打赏管理 |
| 消息中心 | 审核/签约/互动/活动通知分类 |
| 作家课堂 | 资深编辑、大神作家创作经验分享 |
| 年度创作报告 | 年度创作数据回顾（2025年已推出） |

### 4.4 AI交互模式

- **当前无内置AI写作功能**：番茄作家助手本身是纯管理+发布工具，不提供AI续写/生成。
- 平台层面有AI治理：2026年8月起点对AI小说进行治理（移出月票榜/畅销榜），番茄也有类似内容审核机制。
- 作家可使用第三方AI工具创作后在番茄发布。

### 4.5 数据统计与可视化

这是番茄作家助手最核心的差异化能力，数据面板设计非常完善。

#### 作品数据（3大模块）

**① 数据概览**
- 昨日阅读人数 + 环比前日变化
- 昨日X万字读完率（10万/30万/50万/80万/100万5档位，仅显示最高档，20万字后开始显示10万字读完率）
- 品类榜单排名（男频：都市/玄幻/小众；女频：现言/古言/小众；仅展示前100名未断更作品）

**② 质量分析**
- 字数读完率：5档位曲线对比图，可点击标签隐藏/显示各档位
- 章节读完率：每50章一组的趋势图，可定位数据波动章节

**③ 流量分析**
- 流量趋势：阅读人数、追更人数（最近3天内章节）、催更人数、加入书架数（每日趋势）
- 流量来源构成：书城/继续阅读/搜索/书架/分类/其他 6大来源占比分布

#### 收益分析（3大模块）

**① 每日收益**
- 昨日番茄收益 + 环比 + 累计番茄收益（估算值）
- 收益趋势图（按天查询）
- 收益构成：阅读+听书+打赏+催更

**② 每月稿费**
- 单本作品稿费构成：番茄收益（阅读/听书/礼物/催更）+ 集团收益（版权/渠道）
- 集团渠道收益：今日头条分成、番茄畅听TTS分成、抖音SDK分成
- 集团版权收益：有声改编分成、长短视频改编分成
- 每月第二个周四发放，满100元可提现

**③ 礼物收益**
- 礼物总收益、总数量、礼物明细列表

### 4.6 章节管理与发布流程

#### 发布流程

```
注册/登录 → 实名认证 → 创建新书（填书名/分类/简介）
    → 创建章节（标题+正文） → 选择操作：
        ├─ 存草稿（不限字数，字数展示）
        ├─ 直接发布（"下一步"→发布）
        └─ 定时发表（预设时间，可修改）
    → 平台审核 → 已发表/被驳回（站短通知原因）
```

#### 章节管理要点

- 章节状态直观展示（草稿/已发布/审核中/已驳回）
- 支持章节删除与修改（频繁修改会影响读者体验，平台有提示）
- 编辑器护眼模式、标题格式一键切换
- 草稿箱独立管理，创作过程中可随时保存
- 作品完结：非签约作品可在章节管理页申请完结

### 4.7 特色功能

1. **X万字读完率体系**：5档位读完率是番茄独创的质量核心指标，直接关联榜单排名和流量分发。
2. **码字日历+请假机制**：可视化更新记录，支持当月任意一天请假，兼顾全勤规则与人性化。
3. **流量来源6维拆解**：精确到书城/搜索/书架等来源，帮助作者理解流量结构。
4. **稿费透明化**：番茄收益+集团收益双轨，每笔收益来源可追溯。
5. **年度创作报告**：情感化数据回顾，增强作家归属感。
6. **作家课堂**：平台官方内容运营，降低新手创作门槛。

### 4.8 与平台生态的结合方式

## 七、重点分析：作家后台数据面板与发布流程设计

### 7.1 作家后台数据面板设计对比

#### 番茄作家助手 — 行业标杆级数据面板

番茄的数据面板是5款工具中最完善的，其设计逻辑值得深入分析：

**① 指标体系分层清晰**

```
作品数据
├── 数据概览（昨日核心指标 + 环比）
│   ├── 阅读人数
│   ├── X万字读完率（核心质量指标）
│   └── 榜单排名
├── 质量分析
│   ├── 字数读完率（5档位曲线对比）
│   └── 章节读完率（50章一组趋势图）
└── 流量分析
    ├── 流量趋势（阅读/追更/催更/书架 4指标）
    └── 流量来源构成（6来源占比饼图）

收益分析
├── 每日收益（昨日+累计+环比+趋势图）
├── 每月稿费（番茄收益+集团收益 双轨拆解）
└── 礼物收益（总数+明细）
```

**② 设计亮点**

- **读完率为核心质量指标**：将"X万字读完率"作为作品质量的量化标准，并直接关联榜单排名和流量分发，形成"质量→流量→收益"的闭环。
- **环比变化前置**：每个核心指标都显示"比前日"变化，让作者一眼感知趋势。
- **可交互图表**：读完率曲线可点击标签隐藏/显示档位，章节读完率每50章分组切换。
- **流量来源精确拆解**：6大来源（书城/继续阅读/搜索/书架/分类/其他）帮助作者理解流量结构，指导运营动作。
- **收益透明到来源**：每笔稿费可追溯到具体渠道（阅读/听书/打赏/催更/头条分成/抖音SDK/有声改编/短视频改编）。

#### 起点作家助手 — 付费订阅导向的数据面板

- **核心指标不同**：起点以**订阅数（均订/高订）**为核心，而非读完率。这是由付费订阅模式决定的——付费读者的留存比免费读者的读完率更能反映作品价值。
- **月票体系**：月票数据是起点独有的重要指标，关联榜单排名和作家收入。
- **数据粒度**：Web端提供章订阅数据，可定位具体章节的订阅波动。
- **设计不足**：相比番茄，起点App端数据可视化较弱，更多依赖Web端后台。

#### 昆仑引擎可借鉴的数据面板设计要点

1. **核心指标与商业模式对齐**：昆仑若定位为创作工具，应提供"创作质量指标"（如连贯性评分、冲突密度、角色出场均衡度），而非商业指标；若对接发布平台，则需适配各平台核心指标。
2. **环比+趋势图标配**：每个关键指标都应展示环比变化和趋势曲线。
3. **可交互下钻**：从概览→分类→具体章节/段落，支持逐层下钻定位问题。
4. **质量维度量化**：番茄的"读完率"启示我们，创作质量也应可量化（如昆仑已有53维审计，可提炼为可视化质量看板）。
5. **多平台数据聚合**：若昆仑支持多平台发布，应提供跨平台数据对比面板。

### 7.2 发布流程设计对比

#### 番茄作家助手发布流程

```
创建新书 → 创建章节 → [存草稿 | 直接发布 | 定时发表] → 平台审核 → 已发表/驳回
```

- **草稿箱友好**：不限字数，随时保存，展示字数。
- **定时发表可修改**：预设后仍可调整时间。
- **审核反馈明确**：驳回通过站短通知具体原因。
- **护眼模式+标题格式**：编辑器细节体验完善。

#### 起点作家助手发布流程

```
创建作品 → 编辑章节 → [一键发布 | 定时发布] → 预审（风险段落提示）→ 平台审核 → 已发布
```

- **预审机制**：发布前自动检测风险段落并提示，这是起点的差异化优势，显著降低驳回率。
- **发布预览**：可预览读者端效果。
- **悬浮多窗**：写作时不离开编辑器即可查看大纲。
- **多端同步**：手机/电脑无缝切换。

#### 昆仑引擎可借鉴的发布流程设计要点

1. **预审/质量门禁前置**：起点的"风险段落提示"和昆仑已有的8道审计门禁（G1-G8）思路一致，应在发布前自动运行并标记问题段落，而非发布后才发现。
2. **草稿→定时→立即发布 三选一**：番茄的三选项设计清晰，应作为标准发布操作。
3. **发布预览**：模拟读者端阅读效果，提前发现排版/格式问题。
4. **审核反馈结构化**：驳回原因应分类展示（违规/质量/格式），并给出修改建议。
5. **多平台一键发布**：昆仑若支持多平台，应提供"一次编辑，多平台发布"能力，并适配各平台审核规则。
6. **版本管理**：结合昆仑已有的versions模块，发布前自动快照，支持回滚。

### 8.4 昆仑已有优势（应保持强化）

1. **53维质量审计+8门禁**：远超所有竞品的质量管控能力，应可视化呈现。
2. **四层知识图谱**：角色/世界观/伏笔的结构化管理，是彩云小梦和写作猫都不具备的。
3. **多模型抽卡引擎**：比彩云小梦的单模型续写更灵活。
4. **Vibe Writing对话式创作**：比模板式AI写作更自然。
5. **全管线自动写作**：从大纲到完稿的端到端能力，竞品均无。
6. **版本管理与回滚**：比写作猫的"时光机"更系统化。
