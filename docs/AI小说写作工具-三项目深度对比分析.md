### 3.6 天命独有的核心机制

#### 闭环写作流程

```
写前读取 → AI写作 → 门禁校验 → 正文落地 → 状态回写 → 下一章读取最新状态
```

这是天命最核心的创新——**不靠模型上下文窗口，靠结构化状态回写**。

#### 15维事实快照

追踪维度：角色状态、角色位置、角色外貌、冲突进度、伏笔状态、剧情节点、地点状态、势力状态、时间线、物品状态、世界观硬约束、地点特征、秘密状态、誓约约束状态、截止约束状态

#### 12类变更声明 (CHANGES)

AI每章必须以JSON格式交付：
角色状态变化、冲突进度、新剧情节点、伏笔动作、地点状态变化、势力状态变化、时间推进、角色移动、物品流转、秘密揭示、誓约约束变化、截止约束变化

#### 6道生成门禁

| 门禁 | 检查内容 |
|------|---------|
| ① 协议解析 | AI输出必须包含 `---CHANGES---` 分隔符 + 完整JSON |
| ② 引用校验 | CHANGES中引用的ID必须在设计数据中存在 |
| ③ 一致性校验 | 角色状态变化、冲突推进是否与事实快照矛盾 |
| ④ 未知实体检测 | 未登记实体 > 5个或龙套 > 3个 → 打回 |
| ⑤ 描写一致性 | 角色外貌、地点描写是否与档案矛盾 |
| ⑥ 蓝图出场检查 | 指定角色是否实际出现，视角角色仅出现1次会警告 |

#### 四层规划体系

```
大纲 → 分卷 → 章节 → 蓝图
```

蓝图是单章的详细计划，包含：所需情节点、角色出场、环境描述。

#### 本地AI模型

| 模型 | 用途 |
|------|------|
| `bge-small-zh-v1.5` | 语义搜索 / 向量召回（闲置10分钟自动释放） |
| `chinese-roberta-tiny` | 仿人化选词 / 语义守卫 |

## 八、总结

### 三项目的核心差异化

| 项目 | 一句话总结 | 核心创新 |
|------|-----------|---------|
| **马良** | 最完整的商业化AI写作平台 | SaaS化、拆书知识库、LLM可观测、提示词市场 |
| **天命** | 最严谨的数据驱动写作工具 | 15维快照+12类变更+6道门禁、状态回写闭环、本地AI模型 |
| **昆仑** | 最智能的全自动创作引擎 | 8步流水线、Vibe Writing、8门禁33维审计、Neo4j知识图谱 |

### 关键启示

> 三个项目代表了AI写作的三种不同路线：
> - **马良 = 平台化**（编辑器为中心，人类主导，AI辅助）
> - **天命 = 数据化**（状态快照为中心，数据驱动，结构化写作）
> - **昆仑 = 自动化**（流水线为中心，AI主导，人类审核）
>
> **三者并非互斥，而是互补。** 昆仑可以：
> 1. 借鉴天命的**状态回写闭环**，让流水线每步都有结构化状态追踪
> 2. 借鉴天命的**生成门禁**，补充协议解析/引用校验/未知实体检测
> 3. 借鉴马良的**LLM可观测性**，让AI调用完全透明化
> 4. 借鉴两者的**拆书知识库**，让AI从优秀作品中学习

### 昆仑当前最紧迫的3个补强方向

1. **状态回写机制**（借鉴天命）— 让每章生成后的结构化变更自动回写到事实快照
2. **LLM可观测性面板**（借鉴马良）— TraceId追踪 + 成本统计 + 可视化面板
3. **多模型抽卡UI**（借鉴马良）— gacha引擎已有，缺可视化选择界面
