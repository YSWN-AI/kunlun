## 项目宪法

### 代码禁区
1. 禁止修改 `kunlun/` 下第三方依赖的原始代码
2. 所有跨模块调用必须经 `api/routes.py` 或 `agents/message_bus.py`
3. 知识图谱为唯一真实数据源，不得绕过直接写文件
4. 禁止使用裸 `except:`，必须指定异常类型
5. 每次提交仅修改一个模块，单次 AI 回复代码不超过 150 行
6. 新增 LLM 调用必须通过 `gacha/engine.py` 的 GachaEngine

### 关键路径
- 后端入口: `kunlun/api/main.py`
- API 路由: `kunlun/api/routes.py`
- 创作管线: `kunlun/agents/makefile.py` → `_run_chapter_pipeline_async()`
- 主编 Agent: `kunlun/agents/editor.py` → `EditorInChief.chat()`
- 8 门禁审计: `kunlun/audit/gates.py`
- 33 维审计: `kunlun/audit/audit33.py`
- 连载 ICU: `kunlun/audit/icu.py`
- 知识图谱: `kunlun/kg/client.py`
- 文风指纹: `kunlun/style/fingerprint.py`
- 真相文件: `kunlun/truth/__init__.py`
- 前端 (Tauri): `frontend/src/App.vue`

### 常用命令

```bash
# 启动后端
venv\Scripts\activate && uvicorn kunlun.api.main:app --host 127.0.0.1 --port 8000 --reload

# 运行测试
pytest tests/ -q
pytest tests/test_xxx.py -k "test_yyy"
pytest --cov=kunlun tests/

# Tauri 桌面开发
cd frontend && npm run tauri dev

# Tauri 打包
cd frontend && npm run tauri build

# Docker
docker compose up -d
docker build -t kunlun .
```
