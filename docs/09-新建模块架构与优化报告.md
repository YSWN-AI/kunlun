## 三、边际收益优化体系

### 3.1 理论框架

基于**边界效应理论（边际收益递减规律）**：

```
ROI
 │ ╱
 │╱  高收益区（持续优化）
─┼──── 拐点（边际收益开始递减）
 │ ╲
 │  ╲ 低效边界（继续投入无显著提升）
 │   ╲________________________
        投入（代码量/复杂度/维护时间）
```

### 3.2 识别维度

| 投入维度（成本） | 权重 | 产出维度（收益） | 权重 |
|:---|:---:|:---|:---:|
| 代码复杂度 | 35% | 质量贡献 | 40% |
| 维护负担 | 30% | 使用频率 | 25% |
| 运行开销 | 20% | 测试覆盖 | 20% |
| 依赖数 | 15% | 低缺陷面 | 15% |

### 3.3 当前模块 ROI 评级

| 模块 | 层级 | ROI | 状态 | 建议 |
|:---|:---|:---:|:---|:---|
| `gacha/engine.py` | 核心 | ~3.5 | 🟢 健康 | 维持+补充测试 |
| `gacha/circuit_breaker.py` | 核心 | ~3.0 | 🟢 健康 | 补充测试 |
| `agents/architect.py` | 支撑 | ~2.0 | 🟡 正常 | 维持 |
| `agents/writer.py` | 支撑 | ~1.8 | 🟡 正常 | 维持 |
| `agents/makefile.py` | 核心 | ~1.3 | 🟠 注意 | 拆分 _run_chapter_pipeline_async |
| `audit/audit33.py` | 支撑 | ~1.0 | 🟠 注意 | 补充测试 |
| `agents/reflector_agent.py` | 外围 | ~0.4 | 🔴 低效 | 降级/合并 |
| `style_engineer.py` | 外围 | ~0.2 | 🗑️ 已删除 | 直接导入替代 |

### 3.4 监控 API

```
GET  /api/v2/marginal-efficiency/report    → 当前优化报告
GET  /api/v2/marginal-efficiency/health    → 系统健康摘要
POST /api/v2/marginal-efficiency/analyze   → 触发分析
GET  /api/v2/marginal-efficiency/history   → 优化历史
```

### 3.5 关键 KPI

| KPI | 说明 | 告警阈值 |
|:---|:---|:---|
| **CER**（代码效率比） | 核心功能行/总代码行 | < 80% |
| **ETI**（异常透明度） | 非静默异常/总异常 | < 100% |
| **ROI 中位数** | 模块ROI中位数 | < 1.0 |
| **低效模块占比** | 低效模块/总模块 | > 20% |
| **边际ROI斜率** | 连续3轮ROI变化率 | < 0.1 |
