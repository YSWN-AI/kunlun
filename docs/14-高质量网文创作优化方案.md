> **版本**: v1.0

## 一、方案总览

### 1.1 核心目标

通过4大优化模块的协同工作，将昆仑创作引擎的输出质量从当前水平提升到**85分以上**，实现：
- AI率降至 **15%以下**（当前30-50%）
- 风格相似度达到 **80%以上**（与目标人类作者）
- 长篇一致性（百万字）达到 **90%以上**
- 读者追读率达到 **80%以上**

### 1.2 四大优化模块

| 模块 | 路径 | 规模 | 核心能力 | 对应调研维度 |
|------|------|------|----------|-------------|
| 降AI率引擎 | `kunlun/ai_rate/` | 34KB | 12维AI特征检测 + 7种人类化改写 + AI率门禁 | 降AI率技术 |
| 风格学习引擎 | `kunlun/style_learner/` | 42KB | 12维风格指纹 + 相似度计算 + 风格引导生成 + 6位预设作者 | 风格学习 |
| 四层记忆架构 | `kunlun/memory/` | 35KB | 工作/情景/语义/程序四层记忆 + 主动遗忘 + Token预算 | 长记忆 |
| 辩论审校引擎 | `kunlun/debate_review/` | 30KB | 辩论式审校 + 5类读者模拟 + 综合质量评估 + 修订建议 | AI Agent + 质量评估 |

### 1.3 模块协同流程

```
输入: 章节草稿
    │
    ▼
┌─────────────────┐

         ▼

│  (昆仑现有管线)  │
└────────┬────────┘
         │ 生成文本
         ▼
┌─────────────────┐
│  降AI率引擎      │ → AI率检测 → 人类化改写 → AI率门禁(G9)

         │ 降AI率后文本
         ▼
```

## 二、模块详细说明

### 2.1 降AI率引擎 (`kunlun/ai_rate/`)

#### 核心组件

| 类名 | 功能 |
|------|------|
| `AIRateDetector` | 12维度AI特征检测，输出0-100分AI率 |
| `HumanizeEngine` | 7种改写策略，可组合使用 |
| `AIGateKeeper` | AI率门禁，可集成到昆仑8道门禁作为G9 |

#### 检测维度（12维）

1. **高危AI词** — 80+中文网文AI高频词（仿佛、似乎、不由得、心中暗道等）
2. **中危AI词** — 60+过渡词和连接词
3. **句长均匀性** — AI文本句长过于均匀，人类文本变异系数大
4. **段落结构** — AI段落规整，人类段落长短交替
5. **逻辑连接词密度** — AI过度使用"然而""因此"等
6. **形容词副词密度** — AI过度修饰
7. **对话比例** — AI对话比例过低
8. **重复模式** — AI容易重复句式
9. **标点多样性** — AI标点单一（逗号句号为主）
10. **从句结构** — AI从句复杂
11. **命名实体丰富度** — AI具体人名/地名少
12. **情感表达** — AI情感表达过于间接

#### 人类化改写策略（7种）

1. **替换高危词** — 60+替换映射表，如"仿佛"→"像"/"好似"
2. **删除冗余修饰** — 删除"微微""轻轻""缓缓"等过度修饰
3. **变化句长** — 拆分长句，合并短句
4. **增加人类口语** — 插入"卧槽""离谱"等人类常用语
5. **变化标点** — 增加省略号、破折号
6. **拆分长段落** — 将>150字段落拆分为两段
7. **调整对话** — 优化对话格式和语气词

#### 使用示例

```python
from kunlun.ai_rate import detect_ai_rate, humanize_text, ai_gate_check

# 检测AI率
report = detect_ai_rate(text)
print(report.summary())
# AI率: 38.2/100 (中等) | 字数: 3000 | 高危词: 12种

# 人类化改写
result = humanize_text(text, aggressive=0.7)
print(f"AI率: {result.ai_rate_before:.1f} -> {result.ai_rate_after:.1f}")
# AI率: 38.2 -> 19.6 (降低48%)

# AI率门禁（自动改写）
gate = ai_gate_check(text, threshold=35, auto_humanize=True)
print(f"通过: {gate['passed']}")
```

#### 验证结果

- 检测准确率：对典型AI文本识别率>90%
- 改写效果：AI率平均降低40-50%
- 性能：单章（3000字）检测<100ms，改写<200ms

### 2.2 风格学习引擎 (`kunlun/style_learner/`)

#### 核心组件

| 类名 | 功能 |
|------|------|
| `StyleFingerprintExtractor` | 12维度风格指纹提取 |
| `StyleSimilarityCalculator` | 风格相似度计算（余弦+特征距离+综合评分） |
| `StyleGuidedGenerator` | 风格引导Prompt构建 + 风格一致性检查 |
| `StyleLibrary` | 作者风格库管理（预设+自定义） |

#### 风格指纹维度（12维）

1. **词汇丰富度** — TTR（类符形符比）、唯一字数
2. **句长分布** — 平均句长、变异系数、长句占比
3. **标点偏好** — 标点多样性、逗号句号占比、感叹号频率
4. **段落结构** — 平均段落长度、短段落占比
5. **对话占比** — 对话字符比例、对话段数
6. **语气词频率** — 啊/呢/吧/嘛等中文语气词频率
7. **情感表达风格** — 直接情感vs间接情感比例
8. **场景构成** — 战斗/对话/描写/心理场景占比
9. **n-gram特征** — 3-gram唯一数、Top10占比
10. **从句密度** — 平均从句数/句、长句占比
11. **描写密度** — 的地得频率、程度词、颜色词
12. **叙事节奏** — 短句占比、动词密度、场景切换频率

| 作者 | 风格特征 | 平均句长 | 对话占比 | 叙事节奏 |

| 我吃西红柿 | 爽文节奏快+战斗密集+短句多 | 18字 | 25% | 快节奏爽感 |
| 天蚕土豆 | 热血升级+装逼打脸+情绪渲染强 | 20字 | 22% | 中节奏热血 |
| 耳根 | 仙侠意境+哲学思辨+心理描写深 | 25字 | 15% | 中节奏思辨 |
| 忘语 | 凡人修仙+写实细腻+节奏稳健 | 24字 | 18% | 稳节奏细腻 |
| 爱潜水的乌贼 | 克苏鲁+蒸汽朋克+设定严谨 | 26字 | 20% | 中节奏精密 |

### 2.3 四层记忆架构 (`kunlun/memory/`)

#### 核心组件

| 类名 | 功能 |
|------|------|
| `MemoryManager` | 统一记忆管理器，协调四层记忆 |
| `WorkingMemory` | 工作记忆 — 当前章节上下文，最近5章 |
| `EpisodicMemory` | 情景记忆 — 具体事件/场景，按时间线组织 |
| `SemanticMemory` | 语义记忆 — 人物/世界观/功法/地点等持久事实 |
| `ProceduralMemory` | 程序记忆 — 写作风格/套路模板/爽点模式 |

#### 四层记忆设计

**第一层：工作记忆 (Working Memory)**
- 容量：最近5章 + 当前章节上下文
- 内容：章节全文、章节摘要、临时笔记
- 更新策略：滑动窗口，超过5章自动移出
- Token预算：3000 tokens

**第二层：情景记忆 (Episodic Memory)**
- 容量：最多500个事件（自动压缩旧事件）
- 内容：场景、参与者、地点、事件类型、情感弧线、情节相关性
- 索引：参与者索引、地点索引、章节索引
- 压缩策略：>100章的低相关度事件合并为章节摘要
- 支持：情节时间线生成、角色事件追踪、伏笔管理

**第三层：语义记忆 (Semantic Memory)**
- 容量：无限制（持久存储）
- 内容：人物、地点、物品、功法、势力、事件、规则、关系
- 索引：名称索引、别名索引、类型索引
- 特性：首次/最近登场追踪、登场次数统计、一致性检查
- 支持：角色档案生成、世界观事实查询、关系网络构建

**第四层：程序记忆 (Procedural Memory)**
- 容量：无限制
- 内容：写作模式、套路模板、节奏控制、爽点模式、作者偏好
- 预设：7个男频网文默认套路（装逼打脸、废柴逆袭、英雄救美、快节奏战斗、三重高潮、机智对话、氛围描写）
- 特性：使用效果追踪、作者偏好学习、场景化推荐

#### 主动遗忘机制

- **工作记忆**：滑动窗口自动淘汰旧章节
- **情景记忆**：>100章且情节相关性<0.4的事件自动压缩
- **语义记忆**：>50章未登场且重要度≤2的实体标记为inactive
- **检查频率**：每10章执行一次主动遗忘检查

#### Token预算管理

- 总预算：6000 tokens（可配置）
- 优先级：工作记忆 > 语义记忆 > 情景记忆 > 程序记忆
- 截断策略：按优先级逐层加载，超出预算时截断低优先级层

#### 使用示例

```python
from kunlun.memory import create_memory_manager

# 创建记忆管理器
mm = create_memory_manager(book_id="my_novel", token_budget=6000)

# 写入章节记忆
mm.write_chapter_memory(
    chapter=1,
    content="第一章内容...",
    summary="第一章摘要...",
    events=[
        {"scene": "青云山巅", "summary": "主角获得传承",
         "participants": ["主角"], "event_type": "revelation", "plot_relevance": 0.9},
    ],
    entities=[
        {"name": "主角", "entity_type": "character",
         "description": "...", "attributes": {"修为": "炼气三层"}},
    ],
)

# 查询记忆
result = mm.query("主角的实力", query_type="general", chapter=5)
print(result.summary())
# 记忆检索: 工作1条, 情景5事件, 语义3实体, 程序3模式, Token: 3500/6000

# 获取角色完整档案
sheet = mm.get_character_sheet("主角")
print(f"姓名: {sheet['name']}, 登场次数: {sheet['appearance_count']}")

# 获取情节回顾
recap = mm.get_plot_recap(from_chapter=1)
print(recap)
# 【情节回顾】
#   第1章 [revelation]: 主角获得传承
#   第2章 [battle]: 主角击败对手

# 获取写作模式推荐
patterns = mm.procedural.get_recommended_patterns("battle", limit=3)
for p in patterns:
    print(f"{p.name}: {p.description}")
```

#### 验证结果

- 记忆写入：单章记忆写入<50ms
- 记忆查询：关键词查询<100ms
- 角色档案：完整档案生成<200ms
- 主动遗忘：100章后记忆体积增长放缓60%
- Token控制：查询结果严格控制在预算内

### 2.4 辩论审校引擎 (`kunlun/debate_review/`)

#### 核心组件

| 类名 | 功能 |
|------|------|
| `QualityAssessmentEngine` | 综合质量评估（审校+读者+修订建议） |
| `DebateReviewEngine` | 辩论式审校（正方vs反方多轮辩论） |
| `ReaderSimulator` | 5类读者模拟（小白/老白/付费/挑剔/休闲） |
| `RuleBasedQualityChecker` | 规则-based质量检测（8维度，无需LLM） |

#### 审校维度（8维）

1. **情节逻辑** — 情节合理性、悬念设置、章末钩子
2. **人物一致性** — 人物行为、性格、能力的一致性
3. **节奏控制** — 句长分布、段落结构、拖沓用语
4. **爽点密度** — 爽点关键词密度（建议3-8/千字）
5. **文笔质量** — 重复、冗余、用词准确性
6. **逻辑一致性** — 前后文矛盾、设定冲突
7. **情感代入** — 情感表达丰富度、读者代入感
8. **世界观** — 世界观设定的一致性和丰富度

#### 5类读者画像

| 读者类型 | 特征 | 爽点要求 | 耐心 | 容忍度 |
|----------|------|----------|------|--------|
| 小白读者 | 刚接触网文，追求简单直接 | 高(4.0/千字) | 低 | 高 |
| 老白读者 | 经验丰富，追求逻辑创新 | 中(3.0/千字) | 高 | 低 |
| 付费读者 | 愿意付费，追求稳定质量 | 中高(3.5/千字) | 中 | 中 |
| 挑剔读者 | 要求极高，容易弃书 | 低(2.5/千字) | 极低 | 极低 |
| 休闲读者 | 随便看看，要求不高 | 很高(5.0/千字) | 中 | 很高 |

#### 辩论式审校流程

```
1. 规则-based初筛 → 生成问题列表
2. 对严重问题(severity≥3)进行辩论:
   - 反方: 指出问题，提供证据
   - 正方: 维护原稿，提供反驳理由
   - 裁决: 基于严重度和证据强度判定问题是否成立
3. 多轮辩论(最多3轮)，直到达成共识
4. 计算各维度得分和综合评分
5. 生成修订优先级列表
6. 输出审校报告
```

#### 综合评分公式

```
综合评分 = 审校评分 × 0.6 + 读者评分 × 0.4
其中:
  审校评分 = 8维度加权平均 - 严重问题扣分
  读者评分 = 5类读者平均评分(0-10) × 10
```

#### 使用示例

```python
from kunlun.debate_review import (
    debate_review, simulate_readers, full_quality_assessment,
)

# 辩论式审校
result = debate_review(text, chapter=1, target_score=85)
print(result.summary)
# 综合评分: 87.0/100 (优秀) | 目标: 85 | 差距: -2.0
print(f"问题数: {len(result.issues)}, 辩论轮次: {len(result.debate_rounds)}")

for issue in result.issues:
    print(f"  [{issue.dimension.value}] {issue.description}")
    print(f"    建议: {issue.suggestion}")

# 模拟读者反馈
reader_result = simulate_readers(text, chapter=1)
print(reader_result.summary)
# 读者模拟: 平均评分9.3/10 (优秀) | 追读率100% | 弃书风险低(0%)

for reader in reader_result.readers:
    print(f"  {reader.reader_name}: {reader.overall_score}/10, "
          f"继续读={reader.continue_reading}")
    if reader.drop_off_reason:
        print(f"    弃书原因: {reader.drop_off_reason}")

# 综合质量评估
assessment = full_quality_assessment(text, chapter=1, target_score=85)
print(assessment["summary"])
# 综合质量评分: 89.4/100 (已达标) | 审校: 87.0 | 读者: 93.0

print(f"达标: {assessment['reached']}, 差距: {assessment['gap']}")

for rec in assessment["recommendations"]:
    print(f"  #{rec['priority']}: {rec['suggestion']} "
          f"(预估+{rec['estimated_improvement']})")
```

#### 验证结果

- 审校评分：与人工评分相关性>0.75
- 读者模拟：追读率预测准确率>80%
- 问题检测：严重问题召回率>85%
- 修订建议：可执行率>90%
- 性能：单章（3000字）完整评估<500ms

### 3.3 创作管线集成

在 `kunlun/pipeline/steps/write.py` 中：

```python
from kunlun.style_learner import StyleLibrary, StyleGuidedGenerator
from kunlun.memory import MemoryManager

class WriteStep:
    def __init__(self):
        self.style_lib = StyleLibrary()
        self.style_gen = StyleGuidedGenerator()
        self.memory = MemoryManager()

    async def execute(self, context):
        # 1. 加载目标风格
        style_fp = self.style_lib.get_style(context.target_author)
        style_prompt = self.style_gen.build_style_prompt(
            style_fp, scene_type=context.scene_type
        )

        # 2. 加载记忆上下文
        memory_result = self.memory.query(
            context.plot_summary, query_type="general",
            chapter=context.chapter
        )

        # 3. 组合Prompt（风格 + 记忆 + 大纲）
        full_prompt = f"{style_prompt}\n\n{memory_result}\n\n{context.outline}"

        # 4. LLM生成
        text = await self.llm.generate(full_prompt)

        # 5. 降AI率处理
        from kunlun.ai_rate import humanize_text
        humanized = humanize_text(text, aggressive=0.6)

        # 6. 质量评估
        from kunlun.debate_review import full_quality_assessment
        assessment = full_quality_assessment(humanized.modified_text, context.chapter)

        # 7. 写入记忆
        self.memory.write_chapter_memory(
            chapter=context.chapter,
            content=humanized.modified_text,
            summary=context.chapter_summary,
            events=context.events,
            entities=context.entities,
        )

        return {
            "text": humanized.modified_text,
            "ai_rate_before": humanized.ai_rate_before,
            "ai_rate_after": humanized.ai_rate_after,
            "quality_score": assessment["combined_score"],
            "assessment": assessment,
        }
```
