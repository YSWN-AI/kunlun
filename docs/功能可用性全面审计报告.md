## 二、❌ 当前不可用（5个）

### 2.1 LLM 调用 — 全部不可用（核心阻塞）

| 问题 | 详情 |
|------|------|
| **API Key 占位符** | `.env` 中 `OPENAI_API_KEY=sk-your-key-here`、`DEEPSEEK_API_KEY=sk-your-key-here` |
| **Anthropic Key 空** | `ANTHROPIC_API_KEY=` 未配置 |
| **影响范围** | 所有 LLM 调用全部阻塞 |

**受影响的功能**：
- 🚫 章节写作生成（管线 Writer 节点）
- 🚫 Vibe Writing 一句话创作（Orchestrator）
- 🚫 AI 对话聊天（/chat 端点）
- 🚫 编辑对话（EditorInChief）
- 🚫 多模型抽卡（Gacha 4 种模式）
- 🚫 架构师蓝图（Architect）
- 🚫 审计 ICU 自动修复（Auto-fix）
- 🚫 文风指纹 LLM 分析（Style Fingerprint）
- 🚫 社会推演 LLM 辅助（Sociologist）
- 🚫 风格精炼 LLM 增强（Style Refiner）
- 🚫 冲突引擎 LLM 分析
- 🚫 AI 特征检测增强
- 🚫 Prompt 压缩 LLM 重写

**修复方式**：在 `.env` 中填入有效的 DeepSeek/OpenAI API Key。

### 2.2 高级导出引擎 — 完全缺失

| 问题 | 详情 |
|------|------|
| **缺失文件** | `kunlun/exporter/engine.py` 不存在 |
| **`__init__.py` 有损导入** | `from kunlun.exporter.engine import Exporter, ExportFormat` 会报 ImportError |
| **声明 vs 实际** | 声明支持 TXT/EPUB/MOBI/PDF/HTML/DOCX/Markdown 7 种格式 |

**当前实际可用的导出**（直接实现在 API 路由中）：
| 格式 | 状态 |
|------|------|
| TXT | ✅ 可用 |
| HTML | ✅ 可用 |
| Markdown | ✅ 可用 |
| EPUB | ❌ 缺失（需 ebooklib） |
| MOBI | ❌ 缺失（需 calibre，注释说明需独立安装） |
| PDF | ❌ 缺失（需 weasyprint） |
| DOCX | ❌ 缺失（需 python-docx） |

**修复方式**：创建 `kunlun/exporter/engine.py`，实现 `Exporter` 类，逐个支持 EPUB/PDF/DOCX/MOBI 格式。
