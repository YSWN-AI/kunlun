# 资料索引

> 本文件只回答“本次任务该读什么”，不复述原始资料内容。新增权威资料时必须同步更新本索引。

## 强制入口

| 文件 | 作用 | 读取条件 |
| --- | --- | --- |
| AGENTS.md | 启动、权威、记忆和更新规则 | 每个新任务首先读取 |
| 项目档案/项目配置.md | 项目运行参数 | 每个新任务读取 |
| 项目档案/项目状态.md | 当前事实、进度与下一步 | 每个新任务读取 |
| 项目档案/作者长期偏好.md | 跨作品稳定审美 | 初始化相关阶段及所有创作任务 |
| 项目档案/本书创作原则.md | 本书风格、节奏与禁区 | 所有剧情讨论、大纲和正文任务 |
| 项目档案/创作日志.md | 最近已落地变更 | 只读最近1—3条相关记录 |

| 文件 | 主要用途 | 何时读取 |
| --- | --- | --- |
| 项目档案/新项目初始化向导.md | 分阶段建立新书项目 | 初始化或补做缺失建档 |
| 核心创作纲领.md | 高概念、主题、故事发动机、长线 | 全书定位、重大方向和阶段设计 |
| 故事大纲/全书结构模板.md | 建立全书阶段结构 | 初始化长线或大幅重排 |

## 路由补充规则

- 初始化前先走初始化向导，不读取不存在的阶段资料。
- 准备紧邻下一章时读最新衔接卡，不默认回读上一章全文。
- 跨越远期区间时读高精摘要和目标章前近期大纲。
- 只读取与本次任务相关的人物和设定，不全量加载资料库。
- 本索引中的实际文件名应随项目建档同步替换或追加。
